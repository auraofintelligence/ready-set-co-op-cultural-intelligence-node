# Ready S.E.T. Cultural Intelligence Node

A highly visual, multi-page public website exploring one GB200-class rack-scale node in Dunwich for Indigenous and non-Indigenous cultural collaboration, local multimodal models, an island digital twin, practical work and a global network of decentralised intelligences.

S.E.T. means Sustainable Employment and Training. The cooperative is presented as an employment, learning, equipment and shared-service layer around the node rather than a claim over cultural authority.

## What the site contains

- one GB200 NVL72-class rack example rather than a general data-centre proposal
- clear separation between compute capacity, cultural authority, cooperative operations and commercial rights
- practical uses across culture, language, film, music, local services, environmental sensing, law, learning, energy and disaster continuity
- a layered island digital-twin demonstration
- a public description of the Aura path without publishing its deeper private mechanism
- a global node pattern based on interoperability without cultural assimilation
- Australian English throughout
- unique full-width generated raster hero imagery on every public page
- cursor-follow lighting, moving network fields, magnetic buttons, reveal motion and reduced-motion fallbacks
- external links opening in a new window
- floating return-to-top controls and circular previous/next page navigation
- a complete human-readable sitemap and a search-engine sitemap

## Visual sources

The site uses Luke Nathan Hayes's generated raster image library from Future of Life 2045, Grain by Grain documentary and the Ready S.E.T. Cooperative Trust Hub. Each page uses a different image. The source page inside the website records the lineage.

## Run and check locally

Open `index.html` directly or serve the folder with any small static web server.

```bash
npm run check
```

The check covers public pages, internal links, unique hero images, external-link behaviour, route navigation, floating top controls, image formats and prohibited vector image references.

## Source boundaries

The website synthesises Luke Nathan Hayes's working submissions, research and public prototypes. Those materials are design sources rather than independent proof. Nothing in the repository speaks for a First Nation, cultural body, organisation, council or government.
