# AGENTS.md

## Purpose

This repository presents a working exploration of one Dunwich rack-scale intelligence node, Indigenous and non-Indigenous cultural collaboration, a layered island digital twin, Ready Sustainable Employment and Training Cooperative activity, and a global network of decentralised intelligences.

## Voice

- Australian English spelling.
- Plain language.
- Invitational and exploratory phrasing.
- No commands to the reader.
- No claims to speak for a First Nation, family, cultural body, organisation, council or government.
- Sovereignty is not framed as something granted by the technology.
- The cooperative is not framed as cultural authority.
- Initialisms are written out on first use.
- Benchmarks are treated as measuring tools, not winners.
- Timelines appear only where genuinely useful; the project is not forced into staged calendar language.

## Visual system

- Raster images only.
- A different full-width generated hero image on every public page.
- No inline vector drawings, vector icon files or data-image vector strings.
- CSS shapes and the Canvas drawing interface carry diagrams and animation.
- Bright colour, deep contrast, glass, shine, mouse-follow light and restrained motion.
- Reduced-motion fallbacks remain intact.

## Navigation

- Every public page appears in the header and sitemap.
- Every public page contains previous and next route links in the footer.
- Every public page contains a floating return-to-top control.
- External links open in a new window with safe relationship attributes.
- Internal links stay in the same window.

## Content boundaries

- The GB200 NVL72 system remains a working hardware reference, not a procurement declaration.
- 9 Ballow Road remains a place study, not a lease, approval or endorsement claim.
- The deeper private Aura mechanism remains unpublished.
- Cultural material is never described as automatically available for model training.
- Different permission, relationship and human-only layers remain visible.
- Generated imagery is concept imagery and does not prove a built project.

## Checks

`npm run check` remains green before publishing.
